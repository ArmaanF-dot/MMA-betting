# Evaluation: B2/B3, stack, market blend, ablation, betting simulation (public-data features)

Generated by `python -m ufcmodel phase10`. Walk-forward by calendar year; locked holdout is not scored in this report.

## Read this first

- The odds are one scraped pair per bout with no opening/closing label or timestamp. The spec forbids using closing prices at decision time, and these may be close to closing, so the **blend and the betting simulation are optimistic and are not evidence of a real edge**. Closing-line value cannot be measured here.
- Features cover results history, age, physicals, activity and fight-level totals only. No per-round, positional or tagged data, so skills (Phase 4), styles (5), simulator and judging (8) are not built.
- Elo K is fixed at 64; recency half-life fixed at 24 months (not tuned, see decisions.md).
- B2 and B3 use only the feature groups the first ablation kept: elo, age_growth, physical, striking. The ablation table below is the full-model ablation that decided this, rerun here; the pruning was chosen on these same folds, so treat the pruned numbers as slightly optimistic until the one-time holdout confirms them.
