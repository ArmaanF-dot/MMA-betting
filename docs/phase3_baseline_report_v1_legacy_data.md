# Phase 3 partial baseline: Elo vs de-vigged odds

Generated by `python -m ufcmodel backtest`. Test window 2014-11-01 to 2022-09-17 (exclusive); locked holdout 2022-09-17 onward is not scored here.

## Scope and caveats

- Odds come from one scraped betmma.tips pair per bout, with no opening/closing label and no timestamp. They are used as a stand-in for closing odds, so the market comparison is only approximate.
- Only B0 and B1 are built. B2 (logistic) and B3 (LightGBM) need as-of features, which this dataset can't supply honestly (its fighter stats include later fights).
- Elo only (no Glicko-2 yet). K tuned per year from [8, 16, 32, 64, 96, 128, 192, 256]; chosen: 2014: 64, 2015: 96, 2016: 96, 2017: 96, 2018: 96, 2019: 96, 2020: 64, 2021: 64, 2022: 64.
- 74 draws/no-contests in the test window are excluded from scoring.
- Corner A is assigned by a hash of the bout id, so A carries no information.

## Coverage

- Scored test bouts: 3772. With matched odds (the common set below): 3368 (89%).
